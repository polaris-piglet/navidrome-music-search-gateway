# 行为与协议

## 请求处理

客户端 → 网关 → Navidrome。每次请求先向原服务验证身份，在线搜索和下载另受 DOWNLOAD_USERS 控制。首版使用具名账号密码或盐化令牌，不接受 API-key-only 身份推断。认证凭据不交给音乐平台。

普通接口代理；搜索、候选详情、收藏和候选 ID 映射由网关处理。在线候选使用 gw_ 前缀；正式 ID 仅在原生接口确认后绑定。未入库候选没有虚拟歌手/专辑浏览和直接播放能力。

JSON Content-Type 不代表存在正文：空正文、空白或空对象按常规参数转发。getTranscodeDecision 保留查询参数及 JSON 播放能力正文，支持 mediaId 映射。其他非空 JSON 正文明确拒绝，不静默丢弃。不是通用 JSON 参数转换器。

## 收藏事务

单并发入库，来源查询可并发。先下载和校验，再向 NAS 隐藏临时文件提交，读回校验后以 renameat2 禁止覆盖发布。触发扫描后通过原生 download 返回原文件的大小和 SHA256 确认唯一正式 ID，最后以原用户权限收藏。

请求最长约 540 秒，可能超过客户端超时。连接中断取消后续步骤；已提交文件保留供重试。取消收藏更新意图，避免旧请求稍后重新收藏。跨文件系统、HTTP 和 Navidrome 不具备整体原子事务；响应丢失需重试核对。找不到唯一 ID 时明确失败，不以同名歌曲替代。

## 音质

固定所选来源与曲目 ID，只遍历关联档位；网易云尝试 hires/lossless/exhigh/standard/default，QQ 尝试 flac/320/128/default，酷我尝试 flac 与 MP3 档位，酷狗使用该候选关联哈希。

FFprobe 读取真实编码，FFmpeg 完整解码，要求单音轨及约 3 秒内时长偏差。最多 12 档、单档约 40 秒、文件不超过 200 MiB；SSD 保留当前候选和最佳候选。无损优先，其后按实际参数择优；跨编码码率不等同于听感排名。请求无损却返回 MP3 时如实记录。

质量报告不记录下载 URL 或凭据。unavailable_or_requires_auth 为不确定状态，也可能涉及重复地址跳过，不应断言一定需登录。下载原件与标签处理后成品哈希可能不同，必须比较同一阶段。

## 认证扩展与边界

默认匿名。仅显式设置 MUSIC_PROVIDER_AUTH_FILE 时，Go 适配器读取平台名到 Cookie 的私有映射。Compose 默认不挂该文件；没有公网登录界面。需要时使用只读 secret，自行核实平台授权；不能把 Cookie 放入仓库或镜像。

解析后的下载 URL 限制公网 HTTP(S)，但固定上游适配器自己的平台请求属于另一信任边界。已有 path/real_id 复用，不自动升级已下载文件。既有曲库语义去重、登录后高音质替换、所有来源稳定性不在当前保证范围。
