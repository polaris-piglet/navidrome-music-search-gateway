# 验收范围

自动检查覆盖：未认证拒绝、账号隔离、候选 ID、失败不收藏、取消意图、已发布重试、哈希绑定、音质策略、禁止覆盖发布、JSON 播放决策透传、空 JSON 正文兼容和挂载来源检查。测试使用虚构账号及合成音频。

历史客户端集成检查覆盖在线候选搜索、匿名下载回退到实际可用 MP3、索引绑定、真实收藏及 Feishin 播放进度推进。Substreamer 用户反馈空 JSON 请求兼容修复后可以登录。这些是有限样例，不是所有客户端或来源的兼容承诺。

公开 Compose 是通用化后的部署入口，不能把历史私有部署验收视为其全新环境验收。实际部署应验证：挂载来源匹配、无覆盖提交、来源授权、完整下载、正式 ID、收藏结果与媒体播放。健康接口不覆盖这些业务检查。

待扩展：真实无损下载、所有来源、其他架构、长时间运行、挂载失联与恢复。已有文件升级尚未实现，不应用测试来触发旧文件替换。

本次通用化检查：27项测试通过，Linux amd64 Go适配器构建通过，Shell语法、Compose配置与Markdown本地链接检查通过。执行环境未运行Docker引擎，未实际构建或启动通用镜像；此项仍需部署环境验证。
